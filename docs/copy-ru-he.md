# Тексты на иврите с русским переводом

Каждая строка ивритской версии главной. **Иврит** — то, что видит посетитель; **Обратный перевод** — что ивритский текст говорит на самом деле (дословно, для проверки смысла); **Исходник** — русский текст, с которого переводили.

Процесс: два независимых перевода (точный и маркетинговый) → редактор-носитель свёл лучшее и выровнял терминологию → две вычитки (грамматика и естественность; терминология, цифры, RTL) → финальная правка.
