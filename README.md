# Kolbassnik — главная страница (демо-концепция)

Демо новой главной страницы интернет-магазина **kolbassnik.com** (товары для домашней колбасы, Израиль) на русском и иврите.

- **Демо:** https://kolbassnik.kikkey.com/ru/ · https://kolbassnik.kikkey.com/he/
- **Общая ссылка для комментариев:** https://kolbassnik.kikkey.com/ru/?comments=1 (или `/he/?comments=1`)
- Концепция и обоснование: [`docs/DESIGN.md`](docs/DESIGN.md)
- Все тексты на иврите с русским переводом: [`docs/copy-ru-he.md`](docs/copy-ru-he.md)
- Отчёты Lighthouse и скриншоты: [`docs/reports/`](docs/reports/)

Все данные — с настоящего сайта: категории и счётчики, товары и цены (`kolbassnik.com/products.json`), статьи блога, условия доставки и возврата, контакты, логотип. Фото — только реальные снимки и заводские packshot-ы из магазина. Картинки, сгенерированные нейросетью (а их на сайте 60 из 103 проверенных), не используются: на их месте аккуратные заглушки с пометкой «нужно фото».

## Стек

| Что | Как |
| --- | --- |
| Сайт | [Astro](https://astro.build) 7, статическая сборка, vanilla JS |
| Анимации | GSAP 3 + ScrollTrigger, Lenis (только десктоп, грузятся после загрузки страницы) |
| Шрифты | Bona Nova + Rubik (OFL), self-host, по одному файлу на начертание и язык |
| Хостинг | Cloudflare Workers + Static Assets (тот же CDN, что у Pages), домен `kolbassnik.kikkey.com` |
| Комментарии | Cloudflare Worker + Durable Object (SQLite), уведомления: письмо (Resend), Telegram или webhook |

Почему Workers, а не Pages: Cloudflare сейчас рекомендует Workers Static Assets для новых проектов — это тот же глобальный CDN, но статика и API комментариев живут в одном деплое на одном домене (без CORS). Все поддомены `*.kikkey.com` в аккаунте уже устроены так же. Для хранения выбран SQLite в Durable Object, а не D1: у API-токена нет прав на D1, а Durable Object — это тот же SQLite, создаётся вместе с воркером одной командой `wrangler deploy` и не требует отдельной базы.

## Запуск

```bash
npm install
npm run dev        # http://localhost:4321/ru/ — разработка (без API комментариев)
npm run build      # сборка в dist/
npm run preview    # wrangler dev: статика + API комментариев + Durable Object локально, http://localhost:8787/ru/
```

Деплой (нужны `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` в окружении):

```bash
npm run deploy     # astro build && wrangler deploy
```

## Как менять семинары

Файл [`data/seminars.json`](data/seminars.json) — массив `items`. Поля:

| Поле | Что это |
| --- | --- |
| `id` | уникальный идентификатор, латиницей |
| `date` | дата и время по Израилю, например `"2026-12-11T10:00:00+02:00"` (летом `+03:00`) |
| `durationHours` | длительность в часах |
| `title`, `description`, `place` | тексты: `{ "ru": "…", "he": "…" }` |
| `priceILS` | цена в шекелях; `null` — «цена уточняется» |
| `seats` | число мест; `null` — не показывать |
| `image` | имя файла фото в `src/assets/seminars/` (оптимизируется автоматически); `null` — фирменная заглушка |
| `signupUrl` | ссылка записи (Google Form и т. п.); `null` — WhatsApp магазина с готовым текстом на нужном языке |

Прошедшие даты скрываются сами, список сортируется по дате. Пока `"demo": true`, над списком видна пометка «Пример анонса». После правки — `npm run deploy`. Позже этот файл легко заменить админкой (любая headless-CMS или Shopify metaobjects), формат уже готов.

## Комментарии как в Figma

1. Откройте страницу и нажмите **«Комментировать»** (внизу слева) или откройте ссылку с `?comments=1`.
2. При первом входе спросят имя — регистрации нет.
3. Кликните в любое место страницы — появится пин и окно ввода. `Ctrl/⌘ + Enter` — отправить.
4. Клик по пину открывает ветку: можно ответить, отметить «решено» (✓) или вернуть в работу; свой комментарий можно удалить.
5. **«Все комментарии»** — список открытых и решённых, клик переносит к пину. Ссылка на конкретный комментарий: `…/ru/?comments=1#comment-12`.
6. Флажок «С версии на иврите / מהגרסה הרוסית» показывает пины с другой языковой версии (они зеркалятся для RTL).

Как это устроено:
- Пин привязан к элементу: CSS-селектор (`data-cid` / `id` / короткий путь) + относительные координаты внутри его прямоугольника. Поэтому пин остаётся на месте при любой ширине экрана; если элемент исчез, пин встаёт по сохранённым координатам страницы и помечается пунктиром.
- Каждый комментарий знает язык и направление (`ru`/`ltr`, `he`/`rtl`), ширину экрана, секцию и фрагмент текста под пином.
- Скрипт комментариев **не загружается** при обычном просмотре: только по клику на кнопку или по `?comments=1` (отдельный чанк ~8 КБ gz). На скорость страницы не влияет.
- Работает на телефоне: тап ставит пин, окно ввода открывается снизу.

Где хранятся: Durable Object `CommentsStore` (SQLite) воркера `kolbassnik`. Выгрузка всего в JSON: `GET https://kolbassnik.kikkey.com/api/comments`.

### Уведомления о новых комментариях

Воркер отправляет уведомление о каждом новом комментарии, ответе и смене статуса («решено» / «открыт снова») — во все каналы, для которых заданы секреты. Секреты хранятся в Cloudflare, в репозитории их нет. Нужен **один** любой канал:

| Канал | Секреты | Настройка (2 минуты) |
| --- | --- | --- |
| **Письмо** на oleg@kikkey.online | `RESEND_API_KEY`, `NOTIFY_EMAIL` (уже задан: oleg@kikkey.online) | Зарегистрироваться на [resend.com](https://resend.com) **с адресом oleg@kikkey.online** (бесплатно, 100 писем/день) → API Keys → Create → вставить ключ в секрет `RESEND_API_KEY`. Без своего домена Resend шлёт с onboarding@resend.dev на адрес аккаунта — этого достаточно |
| **Telegram** | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | @BotFather → /newbot → токен; написать боту любое сообщение; открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id` |
| **Webhook** | `NOTIFY_WEBHOOK_URL` | POST JSON: подходит Slack (`text`), Discord (`content`), Make / Zapier / n8n (полный объект события) |
| **ntfy push** | `NTFY_TOPIC`, `NTFY_TOKEN` | аккаунт на ntfy.sh → Access token |

Как задать секрет: Cloudflare Dashboard → Workers & Pages → `kolbassnik` → Settings → Variables and Secrets → Add (тип Secret), или из терминала:

```bash
npx wrangler secret put RESEND_API_KEY
```

Почему не анонимные сервисы: бесплатные ретрансляторы без ключа (ntfy.sh без токена, FormSubmit) ограничивают число сообщений по IP, а у Cloudflare Workers общие исходящие IP — при проверке оба вернули 429. Поэтому только каналы с ключом.

## Калькулятор нитритной соли

Логика — [`src/lib/nitrite.ts`](src/lib/nitrite.ts). Нормы взяты только с kolbassnik.com: нитритная соль 0,6 % — 15–17 г/кг (рецепты Артёма: шинка-ветчина, кабаносы, куриный рулет), соль №2 — 20–25 г/кг (карточка товара). По умолчанию стоит нижняя граница. **Дозировки должен проверить владелец** — это отмечено в интерфейсе и в коде.

## Производительность и доступность

- Мобильный Lighthouse (продакшн): Performance 98–99, LCP ≈ 2,2 с, TBT ≈ 0 мс, CLS 0, Accessibility 100, Best Practices 100. SEO 69 — только из-за `noindex`: демо на kikkey.com специально закрыто от индексации, чтобы не конкурировать с kolbassnik.com. Для продакшна: `PUBLIC_INDEXABLE=true npm run build`.
- LCP — текст H1 (без ожидания JS). Шрифты: preload двух файлов на язык, `font-display: swap`, метрически подогнанные фолбэки.
- GSAP/Lenis грузятся только на десктопе после `load` в `requestIdleCallback`; на телефоне — нативный скролл и CSS-появление.
- `prefers-reduced-motion`: без Lenis и анимаций, история «От мяса до колбасы» показывается четырьмя статичными иллюстрациями.
- Изображения: AVIF/WebP, `srcset`, `loading="lazy"`; SVG-«срезы» колбасы — один спрайт `<symbol>`, переиспользуемый через `<use>`.
- RTL: только логические CSS-свойства, иллюстрации и стрелки зеркалятся, числа и латиница изолированы (`dir="ltr"`, `<bdi>`).

## Структура

```
data/seminars.json          семинары (редактирует владелец)
src/i18n/ru.ts, he.ts       все тексты интерфейса
src/data/                   магазин, каталог, блог (реальные данные kolbassnik.com)
src/components/             секции страницы и SVG-иллюстрации
src/scripts/                появление, калькулятор, анимации (motion/), комментарии (review/)
worker/index.js             Worker: редирект по языку, API комментариев, Durable Object, уведомления
scripts/subset-fonts.py     пересборка шрифтов (pip install fonttools brotli opentype-feature-freezer)
fonts-src/                  исходные шрифты OFL (Bona Nova, Rubik) и лицензии
```
